Series Synopsis

Everyone gets one class. Kai drew the card that should not exist.

For three hundred years, every awakened fighter has received one class and climbed the same ladder from F to S. Kai Drane drew a gray card: unclassified, unwanted, and able to learn every class only by starting each one from zero.

When Kai discovers that weak skills can be fused into techniques the system cannot measure, he becomes the anomaly the Awakening Bureau fears. S-rank was the ceiling. He brought a ladder.
